# Project Instructions

## Project context

This repository contains a Python scientific data-processing stack for analysing atomic force microscopy (AFM) images of chip wafers.

## Engineering principles

- Prefer the simplest design that satisfies the approved requirements.
- Give modules and classes clear, cohesive responsibilities.
- Minimize unnecessary coupling and avoid speculative abstractions.
- Make interfaces, assumptions and error conditions explicit.
- Follow established project conventions rather than introducing new patterns without justification.

## Development workflow

- Read the relevant requirements and design documents before making changes.
- Distinguish confirmed requirements, assumptions and unresolved decisions.
- For architectural changes, explain the rationale and meaningful alternatives before implementation.
- Keep changes scoped to the requested task.
- Do not silently deviate from an approved design.

## Code quality and verification

- Follow the project's agreed Python version, type-hinting conventions and coding standards.
- Add or update tests when behaviour changes.
- Run relevant tests and checks when possible, and report their actual results.
- Do not claim scientific correctness solely because software tests pass.
- Clearly report unverified assumptions, limitations and deviations.

## Learning objective

Help me develop my software-design judgement.

For meaningful design decisions, explain why the chosen approach is appropriate, what simpler alternatives exist, and what trade-offs matter. Avoid unnecessary theory for routine changes.
